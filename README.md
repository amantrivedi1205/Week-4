# Retail Sales Analysis and Prediction (Week 4 Capstone)

End-to-end analytics project: exploratory data analysis, a sales regression model, an Excel workbook, Power BI dashboard assets and a written summary of findings.

![Monthly trend](images/02_monthly_trend.png)

## Project Objectives
1. Perform EDA on a retail sales dataset
2. Build a regression model to predict sales
3. Build a Power BI dashboard for key insights
4. Summarise findings and recommendations
5. Deliver a final report (Excel, Python notebook, Power BI)

## Data Note
The assignment brief did not include a dataset, so this project uses a **reproducible synthetic dataset** (Superstore-style, 9,045 raw rows with injected duplicates and missing values) generated by `src/generate_data.py`. To use real data, replace `data/retail_sales_raw.csv` with your file (same column names) and re-run the notebook.

## Methodology
- **Cleaning:** removed 45 duplicate rows, imputed missing categorical values with the mode, parsed dates, engineered Year, Month, Quarter, DayOfWeek, ShipDays and ProfitMargin.
- **EDA:** distributions, monthly and yearly trends, category, region and segment performance, discount impact, correlations, customer concentration.
- **Modeling:** log-transformed `Sales` target; one-hot encoded categoricals; Linear Regression, Random Forest and Gradient Boosting compared on an 80/20 hold-out and 5-fold CV using R2, MAE and RMSE.
- **Excel:** cleaned data plus live SUMIFS/COUNTIF summary tables and charts.
- **Power BI:** star-schema guide, DAX measures and a four-page dashboard design.

## Key Recommendations
1. Cap discounts at 15% and require approval above that
2. Reprice or restructure Tables and Bookcases
3. Promote high-margin lines (Copiers, Paper, Binders, Accessories)
4. Plan inventory for the September to December peak

Full detail: [`reports/summary_findings.md`](reports/summary_findings.md)

## Limitations
Results come from synthetic data and model scores are optimistic; re-validate on real data. A random split was used rather than a time-based split.
